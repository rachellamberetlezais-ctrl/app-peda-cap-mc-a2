# Déposer les applications ici

Déposer les cinq dossiers complets : A2S3M2, A2S3P1, A2S4M1, A2S4M2 et A2S4P1.
Exemple : applications/A2S3M2/index.html et ses ressources dans le même dossier.
Ne pas déposer les dossiers dans assets/ ni remplacer l'index.html du portail.
Les cinq entrées sont déjà enregistrées dans applications.js, sans date différée.
Aucune application de démonstration n'est créée.
