Synthèse de cours : Comparaison de deux tarifs par intersection de droites

1. Modélisation de deux tarifs concurrents
  • Tarif proportionnel pur : $f(x) = a_1 x$ (sans abonnement ni forfait fixe). C'est une fonction linéaire dont la droite représentative $d_1$ passe toujours par l'origine $O(0 ; 0)$.
  • Tarif mixte : $g(x) = a_2 x + b_2$ (forfait fixe + prix variable à l'unité). C'est une fonction affine dont la droite représentative $d_2$ coupe l'axe vertical au point $(0 ; b_2)$ (l'ordonnée à l'origine).
2. Détermination du seuil d'équilibre (Intersection de droites)

Méthode algébrique (par le calcul) :

On résout l'équation du premier degré :

$$f(x) = g(x) \iff a_1 x = a_2 x + b_2 \iff (a_1 - a_2)x = b_2 \iff x_0 = \frac{b_2}{a_1 - a_2}$$

Méthode graphique : Les deux droites se coupent en un point unique $I(x_0 ; y_0)$. Son abscisse $x_0$ donne le volume d'équilibre, et son ordonnée $y_0$ donne le coût commun.

3. Règle de décision économique (La droite située en-dessous)
Sur un repère de coûts, le tarif le plus économique est toujours représenté par la droite située EN DESSOUS :
  • Pour $x < x_0$ : la droite $d_1$ est en dessous de $d_2 \implies$ Le Fournisseur A est le plus avantageux.
  • Pour $x = x_0$ : les deux tarifs sont strictement équivalents ($f(x_0) = g(x_0)$).
  • Pour $x > x_0$ : la droite $d_2$ passe en dessous de $d_1 \implies$ Le Fournisseur B devient le plus avantageux.
